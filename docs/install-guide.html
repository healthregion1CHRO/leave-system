1

สร้างไฟล์ Google Sheets

  1. เข้า sheets.google.com ด้วยบัญชีของหน่วยงาน
  2. กด + สเปรดชีตเปล่า แล้วตั้งชื่อไฟล์ เช่น ระบบวันลาบุคลากร
2

วางโค้ดใน Apps Script

  1. ในไฟล์ชีต เลือกเมนู ส่วนขยาย → Apps Script (Extensions → Apps Script)
  2. ไฟล์ Code.gs ที่เปิดอยู่: ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ Code.gs ที่ได้รับ
  3. กดเครื่องหมาย + ข้างคำว่า "ไฟล์" → HTML → ตั้งชื่อว่า Index (ตัว I ใหญ่ ไม่ต้องพิมพ์ .html) → ลบเนื้อหาเดิม แล้ววางเนื้อหาจากไฟล์ Index.html
  4. (แนะนำ) กด ⚙ การตั้งค่าโปรเจ็กต์ → ติ๊ก แสดงไฟล์ Manifest "appsscript.json" → กลับไปที่ไฟล์ appsscript.json แล้ววางเนื้อหาจากไฟล์ที่ได้รับ
  5. กด 💾 บันทึกโปรเจ็กต์ (Ctrl+S)
3

ตั้งค่าเริ่มต้นและสร้างบัญชี HR คนแรก

  1. กลับไปที่แท็บ Google Sheets แล้ว รีเฟรชหน้า (F5) รอสักครู่จะมีเมนู ระบบวันลา ขึ้นบนแถบเมนู
  2. เลือก ระบบวันลา → 1) ตั้งค่าเริ่มต้นระบบ
  3. ครั้งแรก Google จะขออนุญาต: กด ดำเนินการต่อ → เลือกบัญชี → ถ้าขึ้นว่า "Google ไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต
    ข้อความนี้ขึ้นเพราะเป็นสคริปต์ที่หน่วยงานสร้างเอง ไม่ได้ส่งให้ Google ตรวจ สคริปต์ทำงานเฉพาะในไฟล์ชีตนี้
  4. เลือกเมนูเดิมอีกครั้ง (ถ้าครั้งแรกหยุดที่การขออนุญาต) ระบบจะถาม ชื่อ-นามสกุล และ เลขบัตรประชาชน ของคุณ เพื่อสร้างบัญชี HR คนแรก
ระบบจะสร้างชีต 6 แผ่นให้อัตโนมัติ: บุคลากร · การลา · ยอดยกมา · สิทธิ์การลา · วันหยุด · ตั้งค่า (ห้ามเปลี่ยนชื่อชีตหรือลำดับคอลัมน์)
4

เปิดใช้งานเป็นเว็บแอป (Deploy)

  1. ในหน้า Apps Script กดปุ่มสีน้ำเงิน การทำให้ใช้งานได้ (Deploy) มุมขวาบน → การทำให้ใช้งานได้รายการใหม่ (New deployment)
  2. กดรูปเฟือง ⚙ ข้าง "เลือกประเภท" → เว็บแอป (Web app)
  3. ตั้งค่าดังนี้
    • คำอธิบาย: ระบบวันลา v1
    • ดำเนินการในฐานะ (Execute as): ฉัน (Me)
    • ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)
  4. กด ทำให้ใช้งานได้ → คัดลอก URL ของเว็บแอป (ลงท้ายด้วย /exec) เก็บไว้ นี่คือลิงก์เข้าระบบ
ต้องเลือก "ทุกคน" เพื่อให้บุคลากรที่ไม่มีบัญชี Google ของหน่วยงานเข้าได้ ข้อมูลยังปลอดภัย เพราะทุกคนต้องล็อกอินด้วยชื่อและรหัสผ่าน และเห็นเฉพาะข้อมูลของตนเอง ไฟล์ชีตไม่ได้ถูกแชร์ให้ใคร
5

เข้าระบบครั้งแรกและตั้งค่า

  1. เปิด URL ที่คัดลอกไว้ → ผู้ใช้งาน = ชื่อ-นามสกุลของคุณ · รหัสผ่าน = เลขบัตรประชาชน
  2. ระบบจะแนะนำให้ตั้งรหัสผ่านใหม่ (อย่างน้อย 8 ตัวอักษร) แนะนำให้เปลี่ยนสำหรับบัญชี HR
  3. แท็บ ตั้งค่าสิทธิ์และวันหยุด: ตรวจจำนวนวันลาของแต่ละประเภทบุคลากรให้ตรงระเบียบ และเพิ่มวันหยุดทางจันทรคติ (มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา) วันพืชมงคล และวันหยุดพิเศษตามมติ ครม. (เพิ่มในหน้าเว็บ หรือพิมพ์ต่อท้ายในชีต วันหยุด เป็น 20/05/2570 หรือ 2027-05-20 ก็ได้)
6

เพิ่มรายชื่อบุคลากร

วิธีที่ 1 — ทีละคนในหน้าเว็บ: แท็บ รายชื่อบุคลากร → + เพิ่มบุคลากร → กรอกข้อมูลและเลขบัตรประชาชน → บันทึก

วิธีที่ 2 — หลายคนพร้อมกันในชีต: เปิดชีต บุคลากร แล้วกรอกตั้งแต่แถวว่างถัดไป

คอลัมน์กรอกตัวอย่าง
A idเว้นว่าง (ระบบสร้างให้)
B ชื่อ-สกุลชื่อ-นามสกุล (ใช้เป็นชื่อผู้ใช้ ห้ามซ้ำ)นายสมชาย ดีมาก
C–Fตำแหน่ง · ระดับ · กลุ่มงาน · งานนักวิชาการคอมพิวเตอร์ · ปฏิบัติการ · กลุ่มงานอำนวยการ · งานพัสดุ
G ประเภทบุคลากรข้าราชการ / พนักงานราชการ / พนักงานกระทรวงสาธารณสุข (หรือ พนักงานกระทรวง, พกส.) / ลูกจ้างชั่วคราว · ลูกจ้างประจำ คิดสิทธิ์แบบข้าราชการข้าราชการ
H บทบาทเว้นว่าง = บุคลากร · พิมพ์ HR สำหรับเจ้าหน้าที่ HR
I เลขบัตรประชาชน13 หลัก1234567890121

กรอกเสร็จแล้วเลือกเมนู ระบบวันลา → 2) เข้ารหัสเลขบัตรที่กรอกในชีตบุคลากร ระบบจะเข้ารหัสและลบเลขบัตรออกจากชีตทันที (เลขบัตรที่ผิดจะมีหมายเหตุสีส้มที่ช่องนั้น)

อย่ากรอกเลขบัตรทิ้งไว้ในชีตนานเกินจำเป็น และห้ามแก้ไขคอลัมน์ J–K (salt, hash) ด้วยมือ
เลขบัตรที่กรอกลงชีตจะยังอยู่ใน ประวัติเวอร์ชัน ของ Google Sheets แม้ระบบลบออกแล้ว (PDPA) — ถ้าทำได้ให้ใช้วิธีที่ 1 หรือหลังนำเข้าเสร็จให้ ไฟล์ → ทำสำเนา แล้วใช้ไฟล์สำเนา (สำเนาไม่มีประวัติ แต่ต้องวางโค้ดและ Deploy ใหม่ในไฟล์สำเนา)
7

แจ้งบุคลากรให้เข้าใช้งาน

ส่ง URL ระบบให้บุคลากร พร้อมข้อความนี้:

ระบบตรวจสอบวันลา: [ใส่ลิงก์]
ผู้ใช้งาน = ชื่อ-นามสกุลของท่าน (ไม่ต้องใส่คำนำหน้าก็ได้)
รหัสผ่าน = เลขบัตรประชาชน 13 หลัก
เข้าครั้งแรกแล้วกรุณาตั้งรหัสผ่านใหม่ · ลืมรหัสผ่านติดต่องาน HR

การแก้ไขโค้ดภายหลัง (เวอร์ชันใหม่)

  1. วางโค้ดใหม่ใน Apps Script แล้วบันทึก
  2. การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → กดรูปดินสอ ✎ → ช่อง "เวอร์ชัน" เลือก เวอร์ชันใหม่ → ทำให้ใช้งานได้
  3. ลิงก์เดิมใช้ได้ต่อ ไม่ต้องส่งลิงก์ใหม่
  4. กลับไปที่ชีต เลือกเมนู ระบบวันลา → 1) ตั้งค่าเริ่มต้นระบบ อีกครั้ง (ทำซ้ำได้ ไม่ลบข้อมูล) เพื่อปรับรูปแบบคอลัมน์ให้ตรงกับโค้ดใหม่
  5. ถ้าโค้ดใหม่แจ้งว่าต้องเข้าสู่ระบบใหม่ ผู้ใช้จะถูกพาไปหน้าเข้าสู่ระบบเอง

ความปลอดภัยและข้อควรรู้

  • เลขบัตรและรหัสผ่านเก็บแบบเข้ารหัสทางเดียว (SHA-256 + salt + pepper) ไม่มีใครอ่านกลับเป็นตัวเลขจริงได้ รวมถึง HR
  • ใส่รหัสผิด 5 ครั้ง ชื่อนั้นจะถูกล็อก 15 นาที · ไม่ได้ใช้งานนาน (ไม่เกิน 6 ชั่วโมง) ต้องเข้าสู่ระบบใหม่
  • เมื่อเปลี่ยนรหัสผ่าน หรือ HR รีเซ็ตรหัสผ่านให้ การเข้าระบบค้างไว้ในเครื่องอื่นของบัญชีนั้นจะหลุดทันที · หลังตั้งรหัสใหม่แล้วต้องพิมพ์ให้ตรงทุกตัวอักษร
  • คนที่รู้เลขบัตรประชาชนของผู้อื่นจะเข้าดูข้อมูลการลาของผู้นั้นได้ จึงควรให้ทุกคนเปลี่ยนรหัสผ่านหลังเข้าครั้งแรก (ดูสถานะได้ที่แท็บ "บัญชีผู้ใช้")
  • ห้ามแชร์ไฟล์ Google Sheets ให้คนที่ไม่ใช่ผู้ดูแลระบบ · สำรองข้อมูลได้จาก ไฟล์ → ประวัติเวอร์ชัน หรือ ไฟล์ → ทำสำเนา
  • ข้อมูลบุคลากรเป็นข้อมูลส่วนบุคคลตาม PDPA ควรแจ้งวัตถุประสงค์การใช้ข้อมูลให้บุคลากรทราบ
