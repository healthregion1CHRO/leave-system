# ระบบวันลาบุคลากร (Leave Management System)

ระบบบันทึกและสรุปการลาป่วย ลากิจส่วนตัว (รวมลากิจฉุกเฉิน) และลาพักผ่อน รายบุคคลตามปีงบประมาณ
เจ้าหน้าที่ HR บันทึกการลา บุคลากรเข้าดูวันลาคงเหลือและรายละเอียดการลาของตนเองได้

## โครงสร้าง

| โฟลเดอร์ | รายละเอียด |
|---|---|
| `apps-script/` | เวอร์ชันหลัก: Google Sheets + Apps Script (ล็อกอินด้วยชื่อ-นามสกุล + เลขบัตรประชาชน) |
| `claude-artifact/` | เวอร์ชันหน้าเว็บบน claude.ai (ใช้บัญชี claude.ai ในการเข้าถึง) |
| `docs/install-guide.html` | คู่มือติดตั้งเวอร์ชัน Apps Script ทีละขั้นตอน |

## ติดตั้งเวอร์ชัน Apps Script (สรุป)

1. สร้าง Google Sheets ใหม่ → ส่วนขยาย → Apps Script
2. วาง `apps-script/Code.gs` ในไฟล์ Code.gs และสร้างไฟล์ HTML ชื่อ `Index` วาง `apps-script/Index.html`
3. กลับไปที่ชีต รีเฟรช → เมนู **ระบบวันลา → ตั้งค่าเริ่มต้นระบบ** → กรอกชื่อและเลขบัตรของ HR คนแรก
4. Deploy → เว็บแอป → ดำเนินการในฐานะ: ฉัน · ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน
5. เปิด URL `/exec` แล้วเข้าสู่ระบบ

รายละเอียดเต็มดู `docs/install-guide.html`

## ความสามารถ

- ประเภทการลา: ลาป่วย · ลากิจส่วนตัว (ระบุฉุกเฉินได้) · ลาพักผ่อน — นับวันทำการ ตัดเสาร์-อาทิตย์และวันหยุดราชการ รองรับครึ่งวัน
- สิทธิ์ประจำปี + ยอดสะสมยกมา, วันลาประจำปี + ลาสะสมทุกปี, ลาพักผ่อนสะสมอัตโนมัติ
- ประเภทบุคลากร: ข้าราชการ · พนักงานราชการ · พนักงานกระทรวงสาธารณสุข · ลูกจ้างชั่วคราว (ปรับสิทธิ์ได้)
- กลุ่มงาน/งาน, ระดับ, ค้นหา/กรอง/แบ่งหน้า (10–60 รายการ), วันที่ พ.ศ. พร้อมปฏิทิน, ส่งออกสรุป
- บทบาท HR / บุคลากร — บุคลากรเห็นเฉพาะข้อมูลของตนเอง (กรองฝั่งเซิร์ฟเวอร์)

## ความปลอดภัย

- เลขบัตรประชาชนและรหัสผ่านเก็บแบบเข้ารหัสทางเดียว (SHA-256 + salt ต่อคน + pepper ใน Script Properties) ไม่เก็บตัวเลขจริง
- ล็อกชื่อผู้ใช้ 15 นาทีเมื่อใส่รหัสผิด 5 ครั้ง · session หมดอายุ 6 ชั่วโมง
- แนะนำให้ผู้ใช้เปลี่ยนรหัสผ่านหลังเข้าครั้งแรก
- **ห้าม commit ไฟล์ข้อมูลบุคลากรหรือเลขบัตรประชาชนลง repository นี้**

## หมายเหตุ

ค่าสิทธิ์การลาเริ่มต้นของพนักงานราชการ / พกส. / ลูกจ้างชั่วคราว เป็นค่าประมาณ กรุณาตรวจสอบกับระเบียบที่หน่วยงานใช้จริง
