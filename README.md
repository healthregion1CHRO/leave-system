# ระบบวันลาบุคลากร (Leave Management System)

ระบบบันทึกและสรุปการลาป่วย ลากิจส่วนตัว (รวมลากิจฉุกเฉิน) และลาพักผ่อน รายบุคคลตามปีงบประมาณ
เจ้าหน้าที่ HR บันทึกการลา บุคลากรเข้าดูวันลาคงเหลือและรายละเอียดการลาของตนเองได้

## โครงสร้าง

| โฟลเดอร์ | รายละเอียด |
|---|---|
| `apps-script/` | เวอร์ชันหลัก: Google Sheets + Apps Script (ล็อกอินด้วยชื่อ-นามสกุล + เลขบัตรประชาชน) |
| `tests/` | ชุดทดสอบก่อนขึ้น GitHub (ดูหัวข้อ "ทดสอบก่อนขึ้น GitHub") |
| `docs/install-guide.html` | คู่มือติดตั้งเวอร์ชัน Apps Script ทีละขั้นตอน |

## ติดตั้งเวอร์ชัน Apps Script (สรุป)

1. สร้าง Google Sheets ใหม่ → ส่วนขยาย → Apps Script
2. วาง `apps-script/Code.gs` ในไฟล์ Code.gs และสร้างไฟล์ HTML ชื่อ `Index` วาง `apps-script/Index.html`
   และวาง `apps-script/appsscript.json` (เปิดแสดงไฟล์ manifest ในการตั้งค่าโปรเจ็กต์ก่อน) เพื่อตั้งเขตเวลาไทย
3. กลับไปที่ชีต รีเฟรช → เมนู **ระบบวันลา → 1) ตั้งค่าเริ่มต้นระบบ** → กรอกชื่อและเลขบัตรของ HR คนแรก
4. Deploy → เว็บแอป → ดำเนินการในฐานะ: ฉัน · ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน
5. เปิด URL `/exec` แล้วเข้าสู่ระบบ

รายละเอียดเต็มดู `docs/install-guide.html`

## ความสามารถ

- ประเภทการลา: ลาป่วย · ลากิจส่วนตัว (ระบุฉุกเฉินได้) · ลาพักผ่อน — นับวันทำการ ตัดเสาร์-อาทิตย์และวันหยุดราชการ รองรับครึ่งวัน
- สิทธิ์ประจำปี + ยอดสะสมยกมา, วันลาประจำปี + ลาสะสมทุกปี, ลาพักผ่อนสะสมอัตโนมัติ
- ประเภทบุคลากร: ข้าราชการ · พนักงานราชการ · พนักงานกระทรวงสาธารณสุข · ลูกจ้างชั่วคราว (ปรับสิทธิ์ได้)
- กลุ่มงาน/งาน, ระดับ, ค้นหา/กรอง/แบ่งหน้า (10–60 รายการ), วันที่ พ.ศ. พร้อมปฏิทิน, ส่งออกสรุป
- ยกเลิกวันลา (HR): เมนูแยกตามประเภทการลา ระบุเหตุผล เลือกยกเลิกทั้งรายการหรือเฉพาะบางวัน (ส่วนที่เหลือยังนับเป็นวันลา) และคืนสถานะได้
- บทบาท HR / บุคลากร — บุคลากรเห็นเฉพาะข้อมูลของตนเอง (กรองฝั่งเซิร์ฟเวอร์)

## ความปลอดภัย

- เลขบัตรประชาชนและรหัสผ่านเก็บแบบเข้ารหัสทางเดียว (SHA-256 + salt ต่อคน + pepper ใน Script Properties) ไม่เก็บตัวเลขจริง
  - ถ้านำเข้ารายชื่อโดยกรอกเลขบัตรลงชีตโดยตรง เลขบัตรจริงจะยังอยู่ในประวัติเวอร์ชันของ Google Sheets แม้ระบบเข้ารหัสและลบออกแล้ว
    (PDPA) แนะนำเพิ่มบุคลากรผ่านหน้าเว็บ หรือหลังนำเข้าให้ทำสำเนาชีตใหม่โดยไม่มีประวัติ
- ล็อกชื่อผู้ใช้ 15 นาทีเมื่อใส่รหัสผิด 5 ครั้ง · session หมดอายุเมื่อไม่ได้ใช้งานไม่เกิน 6 ชั่วโมง (อาจเร็วกว่านั้น)
- เมื่อเปลี่ยนหรือรีเซ็ตรหัสผ่าน session เดิมของบัญชีนั้นในเครื่องอื่นจะหมดอายุทันที
- แนะนำให้ผู้ใช้เปลี่ยนรหัสผ่านหลังเข้าครั้งแรก (หลังเปลี่ยนแล้วต้องพิมพ์รหัสให้ตรงทุกตัวอักษร)

## ทดสอบก่อนขึ้น GitHub

```
powershell -ExecutionPolicy Bypass -File tests\run-tests.ps1
```

รัน `Code.gs` บนชีตจำลองในเครื่อง (เข้าระบบ เปลี่ยน/รีเซ็ตรหัส บันทึก/ลบการลา ยอดยกมา วันหยุด สิทธิ์ ส่งออก)
และทดสอบหน้า `Index.html` จริงใน Chrome แบบ headless — ไม่แตะชีตจริง ต้องขึ้น "ผ่านทั้งหมด" ก่อน commit

## อัปเดตอัตโนมัติจาก GitHub (ตั้งค่าครั้งเดียว)

เมื่อตั้งค่าแล้ว ทุกครั้งที่ push ขึ้น `main` ระบบจริงจะดึง `Code.gs` / `Index.html` / `appsscript.json` ไปแทนโค้ดใน Apps Script
สร้างเวอร์ชันใหม่ และชี้ลิงก์ `/exec` เดิมไปที่เวอร์ชันนั้นเองภายใน ~10 นาที (ไม่ต้องวางโค้ดหรือ Deploy เองอีก)

1. เปิด **Google Apps Script API** ที่ https://script.google.com/home/usersettings (บัญชีเจ้าของสคริปต์)
2. ใน Apps Script: **การตั้งค่าโปรเจกต์ → ✔ แสดงไฟล์ Manifest "appsscript.json"** แล้ววาง `appsscript.json` และ `Code.gs` จาก repo ทับ → บันทึก
3. เปิดชีตใหม่ → เมนู **ระบบวันลา → ตั้งค่าอัปเดตอัตโนมัติจาก GitHub** → อนุญาตสิทธิ์ → กด OK (ช่อง token เว้นว่างได้) → ระบบอัปเดตและ Deploy รอบแรกทันที
- GitHub token ไม่บังคับเพราะ repo เป็น public (ถ้าเปลี่ยนเป็น private ต้องใส่ token: https://github.com/settings/personal-access-tokens/new — repo `leave-system`, Contents: Read-only)
- ไม่มี token แล้ว GitHub จำกัดจำนวนครั้ง: ระบบจะอ่านไฟล์จาก branch แทน และรอเห็นโค้ดชุดเดิมสองรอบ (~20 นาที) ก่อนอัปเดต กันได้ไฟล์ต่างรุ่นกัน
- Apps Script เก็บได้สูงสุด 200 เวอร์ชัน ถ้าครบ ให้ลบเวอร์ชันเก่าที่ **ประวัติโปรเจกต์**
- อัปเดตทันทีโดยไม่รอ: เมนู **อัปเดตจาก GitHub ตอนนี้**
- ข้อผิดพลาดล่าสุดเก็บใน Script Properties `GH_ERROR` (ระบบไม่อัปเดตถ้า Code.gs บน GitHub ไม่มีตัวอัปเดต หรือ appsscript.json ขาดสิทธิ์)
- **เพราะ push ขึ้น main = ขึ้นระบบจริง: รัน `tests\run-tests.ps1` ให้ผ่านทุกครั้งก่อน push** (พัฒนาบน branch `dev` แล้วค่อยรวมเข้า main)

## หลังอัปเดตโค้ด (ระบบที่ใช้งานอยู่แล้ว — กรณีไม่ได้ตั้งค่าอัปเดตอัตโนมัติ)

1. วาง `Code.gs` และ `Index.html` ใหม่ทับใน Apps Script → บันทึก
2. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (ลิงก์ `/exec` เดิมใช้ต่อได้)
3. ในชีต เลือกเมนู **ระบบวันลา → 1) ตั้งค่าเริ่มต้นระบบ** อีกครั้ง (ปลอดภัย ไม่ลบข้อมูล) เพื่อตั้งคอลัมน์หมายเหตุ/เลขที่ใบลาเป็นข้อความ
4. ระบบไม่มีรายการวันหยุดราชการติดมาในโค้ดแล้ว — HR เพิ่มวันหยุดเองในหน้า **ตั้งค่า** หรือพิมพ์ในชีต **วันหยุด**
   (รวมวันพืชมงคล / วันหยุดพิเศษตามมติ ครม.)
5. ผู้ใช้ทุกคนต้องเข้าสู่ระบบใหม่หนึ่งครั้ง
- **ห้าม commit ไฟล์ข้อมูลบุคลากรหรือเลขบัตรประชาชนลง repository นี้**

## หมายเหตุ
